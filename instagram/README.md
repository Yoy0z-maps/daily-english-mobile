# 오늘의 문장 — 인스타그램 에셋 키트

앱 UI(`src/theme/colors.ts`, `src/components/ExpressionCard.tsx`)와 같은 색·서체·카드
스타일로 맞춘 인스타그램 콘텐츠 템플릿입니다. 두 가지가 들어 있습니다.

| | 무엇 | 파일 |
|---|---|---|
| 1 | **매일 올리는 게시글 템플릿** — 글자만 바꿔서 바로 PNG 저장 | `daily-template.html` |
| 2 | **피드 꾸미기용 홍보 그리드** — 한 장의 그림을 9칸으로 쪼갠 3×3 무랄 | `promo-grid.html` |

규격은 전부 **1080 × 1350 (4:5)** 입니다. 인스타 프로필 그리드가 4:5 세로 비율로
보여주기 때문에 잘림 없이 딱 맞습니다. (편집기에서 1:1 정사각형으로도 바꿀 수 있어요.)

---

## 1. 매일 올리는 게시글

### 가장 쉬운 방법 — 브라우저에서 글자만 바꾸기

`템플릿열기.command` 를 **더블클릭** 하세요. 브라우저에 편집기가 열립니다.

1. 왼쪽 칸에 오늘의 문장 / 뜻 / 핵심 표현 / 예문을 입력
2. `현재 장 PNG 저장` 또는 `커버 + 본문 2장 모두 저장` 클릭
3. 다운로드 폴더에 받아진 PNG를 인스타에 업로드

- 입력값은 브라우저에 자동 저장돼서 다음에 열면 그대로 남아 있습니다.
- 문장이 길든 짧든 **글자 크기와 여백이 자동으로 맞춰집니다.** 직접 조절할 필요 없어요.
- 테마(라이트/다크)와 비율(4:5 / 1:1)도 드롭다운으로 바꿀 수 있습니다.

### 두 장짜리 구성 (권장)

| 장 | 내용 | 역할 |
|---|---|---|
| 1장 — 커버 | 브랜드 그라데이션 + 문장 + 뜻 | 피드에서 눈에 띄고 스와이프를 유도 |
| 2장 — 본문 | 앱 카드 그대로 (문장·뜻·핵심표현·예문) | 실제 학습 내용 |

한 장만 올릴 거라면 **2장(본문)** 만 쓰면 됩니다. 필요한 정보가 다 들어 있어요.

### 여러 날짜를 한 번에 뽑기

`content/sentences.json` 에 문장을 배열로 넣고:

```bash
node render.mjs daily        # 전체
node render.mjs daily 2      # 2번째 항목만
```

→ `out/daily/DAY-001-1-cover.png`, `DAY-001-2-detail.png` … 로 저장됩니다.
`DAY` 번호는 배열 순서를 따르고, 항목마다 `"day"`, `"handle"`, `"theme"`,
`"ratio"` 를 직접 지정해 덮어쓸 수도 있습니다.

항목 형식은 앱의 `EnglishExpression` 타입과 같습니다:

```json
{
  "sentence": "I'm down for it.",
  "meaning": "나 그거 할래. / 나도 좋아.",
  "keyword": "be down for",
  "keywordMeaning": "~할 의향이 있다, ~에 찬성이다",
  "example": "\"Pizza tonight?\" \"I'm totally down for it.\"",
  "exampleMeaning": "\"오늘 저녁 피자 어때?\" \"완전 좋지.\"",
  "category": "Daily",
  "level": "B1"
}
```

## 2. 피드 꾸미기용 홍보 그리드 (3 × 3)

보내주신 참고 이미지처럼 **한 장의 큰 그림을 가로 3칸으로 쪼개서** 피드를 꾸미는 방식입니다.
전체 3240 × 4050 짜리 무랄을 9칸으로 자른 결과물이 `out/promo/tile-1 ~ 9.png` 입니다.

```bash
node render.mjs promo
```

| 줄 | 내용 | 타일 |
|---|---|---|
| 1줄 | 브랜드 인트로 — 로고 / "하루 한 문장, 진짜 쓰는 영어" / 기능 3가지 | tile-1·2·3 |
| 2줄 | 실제 표현 카드 3장이 한 선반 위에 이어짐 | tile-4·5·6 |
| 3줄 | 잠금화면 위젯 / 연속 학습 / 다운로드 CTA — 아래쪽 브랜드 띠로 연결 | tile-7·8·9 |

### ⚠️ 업로드 순서가 중요합니다

인스타는 **최신 게시글이 왼쪽 위**에 놓입니다. 그래서 번호 역순으로 올려야 합니다.

```
tile-9 → tile-8 → tile-7 → tile-6 → tile-5 → tile-4 → tile-3 → tile-2 → tile-1
```

9장을 다 올리면 프로필이 아래 모습이 됩니다 → `out/promo/_전체미리보기.png` 로 확인하세요.

- **한 줄만 올려도 됩니다.** 예를 들어 1줄만 쓰려면 `tile-3 → tile-2 → tile-1` 순서로 3장.
- `out/promo/_줄1~3-배너.png` 는 3240×1350 통짜 배너입니다. 스토리·블로그·X 등 다른 데
  그대로 쓰기 좋아요 (인스타 피드 업로드용은 `tile-*.png` 입니다).
- 9칸을 다 채우면 이후 데일리 게시글이 올라갈 때마다 그림이 한 칸씩 밀립니다.
  계속 유지하고 싶다면 3장(한 줄) 단위로만 쓰고 주기적으로 다시 올리는 편이 관리하기 쉽습니다.

문구를 바꾸려면 `promo-grid.html` 안의 해당 `.cell` 텍스트만 고치고 다시 렌더하면 됩니다.
브라우저에서 바로 확인하려면 (서버 실행 후):

- 전체 모습 — `promo-grid.html`
- 한 칸만 — `promo-grid.html?view=tile&i=5`
- 한 줄만 — `promo-grid.html?view=row&r=2`

## 폴더 구조

```
instagram/
├─ 템플릿열기.command     더블클릭 → 편집기 실행
├─ daily-template.html    매일 쓰는 게시글 템플릿 (편집기 포함)
├─ promo-grid.html        홍보용 3×3 무랄
├─ brand.css              앱과 동일한 색·서체 토큰 (여기만 고치면 전부 반영)
├─ render.mjs             일괄 렌더러 (headless Chrome, 외부 패키지 없음)
├─ content/sentences.json 일괄 렌더용 문장 목록
├─ assets/logo.png        앱 아이콘 (store-assets/play/icon-512.png 복사본)
├─ fonts/                 Pretendard Variable (오프라인 렌더용)
├─ vendor/                html2canvas (브라우저 저장 버튼용)
└─ out/                   결과 PNG  ← 여기서 꺼내 쓰세요
```

색을 바꾸고 싶으면 `brand.css` 상단의 토큰만 고치면 두 템플릿에 함께 반영됩니다.
앱 테마가 바뀌면 `src/theme/colors.ts` 값과 맞춰 주세요.
