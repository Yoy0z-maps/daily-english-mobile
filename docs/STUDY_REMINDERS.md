# 학습 알림

학습 알림의 기본값은 켜짐입니다. 로그인 후 학습 기록을 불러오면 아직 결정하지 않은 OS 알림 권한을 요청하며, 허용하면 기기 현지 시간 저녁 8시에 알림을 표시합니다. 기존에 사용자가 꺼 둔 설정은 유지합니다. 권한 거절 후에는 자동으로 재요청하지 않으며, 설정에서 학습 알림을 다시 켜서 권한을 변경할 수 있습니다.

- 오늘의 문장을 학습 완료한 날짜(`completedHistory`, `lastCompletedDate`)는 예약에서 제외합니다. 문장을 열어보기만 하거나 복습만 한 경우에는 오늘 문장 완료로 처리하지 않습니다.
- 학습 완료·롤백·서버 동기화 때 예약을 갱신합니다. 로그아웃·알림 끄기는 학습 알림 예약을 취소합니다.
- 알림을 누르면 학습 홈으로 이동합니다. 웹과 심사용 데모에서는 설정을 켤 수 없습니다.
- 앱 종료 후에도 OS가 예약 알림을 표시합니다. OS 알림 설정, 집중 모드, Android 배터리 정책 등에 따라 표시 시점이 달라질 수 있습니다.

## 범위

Expo Notifications의 **로컬 예약 알림**입니다. 서버가 매일 학습 여부를 조회하는 원격 푸시는 아닙니다. iOS 예약 개수 제한을 고려해 오늘부터 60일 범위를 예약하며, 앱 실행·복귀·실행 중에 갱신합니다. 60일 동안 한 번도 앱을 열지 않으면 추가 알림이 없습니다. 다른 기기에서 한 학습은 이 기기에서 동기화되어야 반영됩니다. 시간대를 바꾼 경우에도 앱에 복귀하면 새 현지 시간으로 다시 예약합니다.

여러 기기에서 실시간으로 학습 여부를 판단하거나 무기한 미접속 사용자에게 알림을 보내려면 푸시 토큰 저장, APNs/FCM 인증, 서버 스케줄러와 발송 내역 관리가 필요합니다.

## 빌드 및 기기 확인

네이티브 의존성 `expo-notifications`와 config plugin을 추가했으므로 기존 바이너리에 JS 업데이트만 적용해서는 사용할 수 없습니다. 네이티브 프로젝트 변경을 보존하면서 `npx expo prebuild --no-install`로 설정을 반영한 뒤 iOS Pods 설치 및 iOS/Android 앱 재빌드가 필요합니다. 원격 푸시 토큰은 사용하지 않습니다.

실기기에서 다음을 확인합니다.

1. 권한 허용·거절, OS 설정에서 권한 변경 후 설정 스위치 조작.
2. 20시 전 미학습 상태에서 앱을 종료했을 때 알림 수신.
3. 20시 전 학습 완료 후 당일 알림이 오지 않는지 확인.
4. 다음 날에는 미학습 상태에서 다시 수신하는지 확인.
5. 알림 끄기·로그아웃 후 수신하지 않는지 확인.
6. 앱이 종료된 상태와 실행 중인 상태에서 알림을 눌렀을 때 학습 홈 이동.

참고: https://docs.expo.dev/versions/v56.0.0/sdk/notifications/
