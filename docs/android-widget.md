# Android 홈 화면 위젯

Android 위젯 원본은 `native/android/widget`에 있습니다. `plugins/withAndroidDailyEnglishWidget.js`가 Expo prebuild에서 Kotlin 소스와 리소스를 복사하고 Manifest receiver 및 React Native 패키지를 등록합니다. git에서 제외된 `android/`만 수정하면 clean prebuild 시 사라지므로 원본을 수정해야 합니다.

## 빌드와 테스트

1. `npx expo prebuild --platform android --no-install`
2. 에뮬레이터 실행 후 `npm run android` 또는 Android Studio에서 Run. 네이티브 코드 추가이므로 Metro 새로고침만으로는 적용되지 않습니다.
3. 앱 홈 화면을 한 번 열어 현재 학습 데이터를 저장합니다.
4. 런처 홈 화면의 빈 공간 길게 누르기 → 위젯 → **오늘의 문장** → 추가.
5. 문장·뜻·핵심 표현·연속 학습일, 위젯 크기 변경, 탭해서 앱 홈 열기, 학습 완료 후 데이터 갱신을 확인합니다.

위젯을 여러 개 추가해도 모두 함께 갱신됩니다. 데이터가 없을 때는 앱 실행 안내를 표시합니다. 저장은 앱 전용 SharedPreferences를 사용하며 위젯은 앱 프로세스가 실행 중이지 않아도 저장된 데이터를 읽을 수 있습니다.

## 날짜 변경

앱에서 저장한 완료 날짜 이후에는 미리 저장한 다음 문장을 선택합니다. 추가 학습 없이 여러 날이 지나도 한 문장까지만 진행하며, 마지막 완료일이 어제보다 오래됐으면 연속 학습일을 0으로 표시합니다. 기기의 현지 날짜를 사용합니다.

앱 데이터 저장 시 즉시 갱신하고, 시스템 위젯 업데이트(30분 주기) 및 날짜·시간대 변경 방송에서도 갱신합니다. 절전 모드 등 Android 스케줄링에 따라 갱신이 지연될 수 있으며 정확히 자정에 변경되는 것은 보장하지 않습니다. 서버에서 새 콘텐츠를 직접 다운로드하지는 않습니다.

## 목록에 안 보이는 경우

기존 버전에는 iOS 위젯만 있었으므로 새 네이티브 APK 설치가 필요합니다. 설치 후 앱을 한 번 실행하고 위젯 선택 화면을 다시 여세요. Expo Go에서는 이 커스텀 네이티브 위젯을 제공하지 않습니다.

`adb shell dumpsys appwidget`에서 `com.dailyenglish.widget.DailyEnglishWidgetProvider`를 검색하면 시스템 등록 여부를 확인할 수 있습니다.

## iOS와 맞춘 디자인

- 홈: 파랑·보라 장식이 있는 그라데이션, 책 아이콘, 우측 레벨 배지, 핵심 표현 칩. 시스템 다크 모드에 대응합니다.
- 홈 위젯의 폭이 230dp 미만이면 iOS 소형 구성(작은 제목과 문장, 핵심 단어만 표시)으로 전환합니다.
- `오늘의 문장 · 원형`, `오늘의 문장 · 문장`, `오늘의 문장 · 한 줄`은 iOS 잠금화면 accessory 디자인을 옮긴 별도 선택 항목입니다. 원형은 EN과 연속 학습일 또는 레벨, 문장형은 문장과 뜻, 한 줄형은 EN과 문장을 표시합니다. 잠금화면용 흰색 단색 디자인입니다.
- Android 잠금화면의 지원 여부·배치·크기는 OS와 제조사에 달려 있습니다. `keyguard` 선언만으로 잠금화면 위젯 기능이 없는 기기에 기능이 생기지는 않습니다. 지원 기기의 잠금화면 위젯 선택기에서 추가하세요. 홈 화면에서도 accessory 디자인을 선택해 확인할 수 있습니다.
- 기존 홈 위젯은 그대로 업데이트됩니다. 잠금화면 호스트가 keyguard category를 전달하면 기본 위젯도 간결한 문장형으로 표시합니다. 이를 전달하지 않는 최신 호스트에서도 별도 accessory 항목을 선택하면 해당 디자인을 사용할 수 있습니다.

공식 참고: https://android-developers.googleblog.com/2025/03/widgets-on-lock-screen-faq.html

디자인 변경 검증: Android API 36.1 에뮬레이터에서 APK 빌드·설치, 홈 위젯의 소형/중형 전환과 라이트/다크 모드를 확인했습니다. 잠금화면 전용 호스트에서의 실제 배치는 별도 지원 기기에서 확인해야 합니다.
